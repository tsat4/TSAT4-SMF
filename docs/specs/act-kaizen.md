## สูตรและการประเมิน (FM-QSM-039 ด้านหน้า + ด้านหลัง)

- **ด้านหน้า:**
  - จำนวนเงินที่ใช้ในการปรับปรุง = ค่าแรง + ค่าอุปกรณ์ (บาท)
  - ระยะเวลาในการคืนทุน (เดือน) = จำนวนเงินที่ใช้ ÷ ผลตอบแทนต่อเดือน · ไม่มีผลตอบแทน = ไม่มีค่า (`kaizenMoney`)
- **ด้านหลัง (`kaizenEval`):**
  - **ก1. ลดชั่วโมงการทำงาน (`saved_hours` ชม./ปี):** ≥ 8,001 = A (500฿), 5,001–8,000 = B (300฿), 3,001–5,000 = C (200฿), 1,001–3,000 = D (100฿), 501–1,000 = E (80฿), 201–500 = F (50฿), 81–200 = G (40฿), 31–80 = H (30฿), 10–30 = I (20฿)
  - **ก2. คำนวณเป็นตัวเงิน (`saved_baht` บาท):** ≥ 3,000,001 = Q (1,500฿), 1,000,001–3,000,000 = R (1,000฿), 500,001–1,000,000 = S (500฿), 300,001–500,000 = T (300฿), 100,001–300,000 = U (200฿), 50,001–100,000 = V (100฿), 10,001–50,000 = W (80฿), 3,001–10,000 = X (50฿), 301–3,000 = Y (20฿), 100–300 = Z (10฿)
  - **ข. คำนวณเป็นเงินไม่ได้ (6 หัวข้อ × 0–5 คะแนน, รวม 30):** (1) ความคิดริเริ่ม/ความใหม่ (2) ความพยายาม/วิจัย/ค้นคว้า/ทดลอง (3) ความสมบูรณ์ & การประยุกต์ใช้ (4) คุณภาพ (5) ความปลอดภัย (6) ประสิทธิภาพ → คะแนนรวม 25–30 = J (100฿), 22–24 = K (50฿), 19–21 = L (30฿), 16–18 = M (20฿), 11–15 = N (15฿), 4–10 = P (10฿)
  - `eval_grade` = เกรดที่ได้จาก ก1 / ก2 / ข มารวมกัน · `eval_reward` = ผลรวมเงินรางวัล (บาท)

## สิทธิ์

- **ตัวแทนสมาชิกประจำแผนก (`member`)**: ดูแลแผนกตนเอง เลือกสมาชิกในสังกัด (`mt_main_employee.department`) สร้างและส่งเรื่อง Kaizen เข้าระบบได้ (ชื่อคนเดิมส่งเรื่องเพิ่มได้ไม่จำกัด) และแก้ไขใบในแผนกตนเองได้ก่อนอนุมัติ
- **ผู้จัดการประเมิน (`manager_id` ของแผนกนั้นใน `mt_kaizen_team`) / ประธาน / รองประธาน / ผู้ดูแลของปี**: ประเมินผล Kaizen หลังส่งเรื่อง (กรอกช่วงเวลาปฏิบัติ, ก1 ชั่วโมง, ก2 ตัวเงิน, ข คะแนน 6 หัวข้อ, อนุมัติ / ไม่เข้าหลักเกณฑ์ + ความเห็น)
- **ผู้ดูแล (`admin`)**: ตั้งค่าทีมประจำปี (เพิ่ม/แก้ไขตัวแทนสมาชิก แผนก จำนวนเรื่องที่ต้องส่งต่อปี และผู้จัดการประเมิน) · แก้ / ลบได้ทุกใบ · เลือกพนักงานทุกแผนกได้

## หน้าจอ

- **Dashboard:** Summary (การ์ด KPI + เป้าส่งปีนี้ + รางวัลรวม · กราฟรายเดือน · ตารางตามหน่วยงานแสดงตัวแทนสมาชิก ผู้จัดการประเมิน เป้าต่อปี ส่งแล้ว อนุมัติ เงินที่ใช้ ผลตอบแทน คืนทุน เงินรางวัล) · Schedule (Planner ดูอย่างเดียว) · Team (ผังองค์กร 3 ระดับ ประธาน · รองประธาน/ผู้ดูแล · ตัวแทนสมาชิกประจำแผนกพร้อมเป้าส่งและผู้จัดการประเมิน + ตารางตัวแทนสมาชิกประจำปี)
- **Transaction:** ตารางใบ Kaizen ของปี (แสดงเกรดและเงินรางวัล) · ปุ่ม `ประเมิน Kaizen` สำหรับผู้จัดการประจำแผนก/ประธาน/รองประธาน/ผู้ดูแล · ฟอร์มใบ Kaizen (ตัวแทนสมาชิกเลือกพนักงานในสังกัดจาก dropdown ได้, ด้านล่างแสดงสรุปผลประเมินด้านหลังฟอร์ม)
- **Setting:** แผนงาน (Planner) · ทีม (เพิ่ม/แก้ไขสมาชิกประจำปี ระบุแผนก จำนวนเรื่องที่ต้องส่งต่อปี และเลือกผู้จัดการประเมิน Kaizen)
