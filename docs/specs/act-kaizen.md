## ตาราง (Tx Data)

| ตาราง | มาจาก | หมายเหตุ |
|---|---|---|
| `mt_kaizen_team` | แม่แบบ | ผู้ดูแล (เลขานุการ) = `admin`, ประธานกิจกรรม = `chairman`, รองประธาน = `vice`, คณะกรรมการ = `auditor` (+ กลุ่ม A–Z), ตัวแทนหน่วยงาน = `member` (+ หน่วยงาน) |
| `mt_kaizen_task` | แม่แบบ | แผนงาน (Project Planner ตามกฎเดียวกับ 5S / 100P) |
| `mt_kaizen_setting` | แม่แบบ | ยังไม่ใช้ |
| `tx_kaizen_entry` | ใหม่ | 1 แถว = 1 ใบ Kaizen (ด้านหน้า) |
| bucket `img_kaizen` | แม่แบบ | รูปก่อน / หลัง (`entry/<id>_<before|after>_<เวลา>.jpg`) |

`tx_kaizen_entry`: `reg_no` ลงทะเบียนเลขที่ `KZ-<ปี>-<ลำดับ 4 หลัก>` (server ออกให้ตอนสร้าง) · `title` เรื่อง · `kind` บุคคล / ทีม / มาจาก QCC · `members` สมาชิกทีม ·
ผู้เสนอ `employee_id` + `department` (จาก Mx Data) · `submitted_on` วันที่ (ปีของใบ = ปีของวันที่) · `before_text` สภาพปัจจุบันหรือปัญหา · `after_text` วิธีการปรับปรุง ·
`before_photo` / `after_photo` · `types` Q C D S M E O(อื่นๆ) + `other_type` · `cost_labor` ค่าแรง · `cost_material` ค่าอุปกรณ์ · `return_month` ผลตอบแทน บาท/เดือน ·
`benefit` ผลที่คิดเป็นเงินไม่ได้ · `status` DRAFT ร่าง → SUBMITTED รอพิจารณา → APPROVED อนุมัติ / REJECTED ไม่เข้าหลักเกณฑ์ + `review_note`

## สูตร

- จำนวนเงินที่ใช้ในการปรับปรุง = ค่าแรง + ค่าอุปกรณ์ (บาท)
- ระยะเวลาในการคืนทุน (เดือน) = จำนวนเงินที่ใช้ ÷ ผลตอบแทนต่อเดือน · ไม่มีผลตอบแทน = ไม่มีค่า (`kaizenMoney` ใน server, หน้าจอคำนวณให้ดูทันที)

## สิทธิ์

- ทุกคนที่ล็อกอิน: สร้างใบของตนเอง · แก้ / เปลี่ยนรูปได้จนกว่าจะอนุมัติ · ลบได้เฉพาะใบร่าง · ส่งพิจารณา (ร่าง หรือ ไม่เข้าหลักเกณฑ์ → รอพิจารณา)
- ประธาน / รองประธาน / ผู้ดูแลของปี: อนุมัติ / ไม่เข้าหลักเกณฑ์ (+ ความเห็น)
- ผู้ดูแล: แก้ / ลบได้ทุกใบ · สร้างใบแทนคนอื่นได้ (ส่ง `employeeId`) · แผนงาน + ทีม ใน Setting

## หน้าจอ

- **Dashboard:** Summary (การ์ด: ส่ง / อนุมัติ / เงินที่ใช้ / ผลตอบแทนต่อเดือน / คืนทุนรวม · กราฟรายเดือน อนุมัติ + รอพิจารณา · ตารางตามหน่วยงาน) · Schedule (Planner ดูอย่างเดียว) · Team
- **Transaction:** ตารางใบ Kaizen ของปี (กรองสถานะ / หน่วยงาน / ค้นหา) · สร้าง / ดู / แก้ไข / ลบ · อนุมัติ / ไม่เข้าหลักเกณฑ์ · ฟอร์มตามด้านหน้าของ Excel: หัว (เรื่อง ประเภท วันที่ ผู้เสนอ สมาชิก) · ก่อน / หลัง (รูป 16:9 ครอปให้อัตโนมัติ + ข้อความ) · ประเภท Kaizen · ผลที่คิดเป็นเงิน (ค่าแรง + ค่าอุปกรณ์ → เงินที่ใช้, ผลตอบแทน บาท/เดือน → คืนทุน เดือน) · ผลที่คิดเป็นเงินไม่ได้
- **Setting:** แผนงาน (Planner) · ทีม
