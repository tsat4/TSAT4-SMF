## สูตร

- 023 คะแนน = ความถี่ × ความรุนแรง × ความเป็นไปได้ (ตัวอย่าง Excel: 2 × 3 × 3 = 18 = หัวข้อที่เลือก)
- 030 ค่าใช้จ่ายรวม = Σ (ค่าแรง + อื่นๆ) · คืนทุน (เดือน) = ค่าใช้จ่ายรวม ÷ ผลตอบแทนต่อเดือน
- ความคืบหน้า = จำนวนขั้นตอน (ใน 11 ขั้น) ที่มีสัปดาห์ Actual ÷ 11

## สิทธิ์

- ทุกคนที่ล็อกอิน: สร้างโครงการโดยตัวเองเป็นหัวหน้ากลุ่ม · หัวหน้ากลุ่ม / ผู้สร้างแก้ได้จนกว่าจะอนุมัติ · ลบได้เฉพาะร่าง · ส่งพิจารณา
- คณะกรรมการ (ประธาน / รองประธาน / ผู้ดูแลของปี + ผู้บริหารตามระดับสิทธิ์ภาพรวม): อนุมัติ / ไม่ผ่าน + ความเห็น
- ผู้ดูแล: แก้ / ลบได้ทุกโครงการ เปลี่ยนหัวหน้ากลุ่มได้ · แผนงาน + ทีมใน Setting
- ค้นหัวหน้ากลุ่ม / ผู้จัดการ: `GET qcc/people` เปิดให้ทุกคนที่ล็อกอิน (ค้นพนักงานของกิจกรรมเปิดเฉพาะทีม)
