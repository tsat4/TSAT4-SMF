## ปัญหาของโครงสร้างตอนนี้

- 1 กิจกรรม = EF ตัวเดียว = ค่ารวมก้อนเดียว (`kgco2e`) ไหลเข้า Scope เดียว → แยกส่วนที่ต้อง **รายงานแยก** ไม่ได้
  - B7 / E10 / E20: CO₂ ส่วนชีวมวล ต้องรายงานแยก ไม่รวมยอด · CH₄ / N₂O ส่วนชีวมวลยังอยู่ Scope 1
  - ต้นน้ำของเชื้อเพลิง / ไฟฟ้า (ผลิต + ขนส่งก่อนถึงเรา) → Scope 3 หมวด 3
  - สารทำความเย็นนอกพิธีสารเกียวโต (R-22) → รายงานแยก (แถว "อื่นๆ" ในตารางสรุป TGO)
- GWP เป็นคอลัมน์ตายตัว (co2, ch4, n2o, sf6, nf3) → สารทำความเย็นแต่ละชนิด (R-32, R-134a, R-410A …) มี GWP ของตัวเอง ใส่ไม่ได้
- วิธีคำนวณมีแค่ `septic` · ขนส่ง (ตัน·กม.), สารทำความเย็น (kg ที่เติม), น้ำมันผสม (% ไบโอ) ทำไม่ได้
- ข้อมูลรายปี (ปีฐาน, ปริมาณผลิต, ปิดปี) กระจายอยู่ใน `mt_cfo_setting` เป็น key-value
- หลักฐานเป็นแค่ข้อความ/ลิงก์ (`doc`) · ไม่มีคะแนนคุณภาพข้อมูล

## หลักการ

1. **ยอด Scope ไม่เปลี่ยนวิธีคิด:** tCO₂e = ปริมาณ × `kgco2e` (ค่ารวมที่ TGO ประกาศ) / 1000 เหมือนเดิม → ข้อมูลเดิม 187 รายการได้ยอดเท่าเดิม (Scope 1 = 188.863, Scope 2 = 6,642.52)
2. **ส่วนที่รายงานแยกเป็นแถวเพิ่มของ EF** (`mt_cfo_ef_part`) ไม่ปนกับยอด Scope
3. **แยกก๊าซ** ใช้ส่วนประกอบ EF รายก๊าซ × GWP (สำหรับตารางสรุปตามก๊าซ)
4. **วิธีคำนวณเป็นรหัส** + ช่องที่ต้องกรอก (jsonb) → เพิ่มวิธีใหม่ไม่ต้องแก้ตาราง
5. **ผลไม่เก็บ คำนวณผ่าน view** · รายการเก็บ `ef_id` / `gwp_code` ที่ใช้ตอนบันทึก ผลย้อนหลังไม่เปลี่ยน (เหมือนเดิม)
6. ชื่อตารางยังเป็น `mt_cfo_*` (แม่แบบเดิม) · CFP มาอ่าน EF / GWP ชุดนี้ภายหลัง

## วิธีคำนวณ (`mt_cfo_method`) — แผนเดิม

| code | ช่องที่กรอก | ปริมาณที่คิด | ไปที่ |
|---|---|---|---|
| `direct` | ปริมาณ | ปริมาณ × EF | ตามหมวดของ EF |
| `blend` (B7 / B10 / E10 / E20) | ลิตร, % ไบโอ (ค่าตั้งต้นจากกิจกรรม) | ฟอสซิล = ลิตร × (1 − %) × EF ฟอสซิล · ไบโอ = ลิตร × % × EF ไบโอ | ฟอสซิล + CH₄/N₂O ไบโอ → Scope 1 · CO₂ ไบโอ → รายงานแยก · ต้นน้ำ → Scope 3 หมวด 3 |
| `septic` | คน, วัน | kg CH₄ = คน × วัน × BOD × 0.001 × I × B0 × MCF (เดิม) | Scope 1 |
| `transport_fuel` (รถของเรา) | ลิตร (หรือ ใช้ `blend`) | เหมือนเชื้อเพลิง | Scope 1 |
| `transport_distance` (จ้างขนส่ง) | ตัน, กม. (หรือ เที่ยว × กม.) | ตัน·กม. × EF ต่อ tkm | Scope 3 หมวด 4 (ขาเข้า) / 9 (ขาออก) |
| `refrigerant` | ชนิดสาร, kg ที่เติม | kg × GWP ของสาร | Scope 1 · สารนอกเกียวโต (R-22) → อื่นๆ |
| `electricity` | kWh | kWh × EF กริดของปีนั้น | Scope 2 (location-based) |

### Fr-04.1 บัญชีรายการก๊าซเรือนกระจก (และ Fr-04.2 ปีฐาน = ฟอร์มเดียวกัน เลือกปีฐาน)

- 1 แถว = 1 กิจกรรม รวมทั้งปี · จัดกลุ่ม: ขอบเขต 1 → **การปล่อย GHG โดยตรงที่ทำการรายงานแยก** → ขอบเขต 2 → ขอบเขต 3 · แถวรวมแต่ละกลุ่ม + รวม Scope 1+2 และ 1+2+3
- คอลัมน์ตามฟอร์ม: รายการ · หน่วย · ปริมาณ · EF (kg GHG/หน่วย) CO₂ / Fossil CH₄ / CH₄ / N₂O / SF₆ / NF₃ / HFCs / PFCs (+ GWP ของ HFCs / PFCs) · GHG นอกข้อกำหนด (EF + GWP) · Total (kgCO₂e/หน่วย) · ที่มาข้อมูล (1st: Self collect / Supplier · 2nd: TH LCI DB / TGO EF / Thai Res. / Int. DB · Other) · Substitute · แหล่งอ้างอิง · ผลคูณ (ton GHG) รายก๊าซ · ผลคูณ (tCO₂e) รายก๊าซ + Other · Total GHG (tCO₂e) · สัดส่วน (%) ในกลุ่ม · (%) Scope 1+2 · (%) Scope 1+2+3 · คำอธิบายเพิ่มเติม
- สูตรตามฟอร์ม: Total EF = Σ EF ก๊าซ × GWP (AR5: CO₂ 1, Fossil CH₄ 30, CH₄ 28, N₂O 265, SF₆ 23,500, NF₃ 16,100) + HFCs × GWP + PFCs × GWP · tCO₂e = ปริมาณ × Total / 1000 · รายงานแยก: Total = CO₂ + EF นอกข้อกำหนด × GWP, ส่วนนอกข้อกำหนดลงคอลัมน์ Other
- ต้องการจากโครงสร้างใหม่: `mt_cfo_ef_part` (EF รายก๊าซ + SF₆ / NF₃ + นอกข้อกำหนด), `mt_cfo_ef.source_type` (1st / 2nd / Other + ฐานข้อมูล), `substitute` · กิจกรรม → กลุ่ม "รายงานแยก" ตาม `report` ของ EF

5. **ส่งออกรายงาน** ตามแบบฟอร์ม TGO (Excel)
