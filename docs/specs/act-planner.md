# Project Planner (100P และ 5S)

ผู้ใช้สั่ง 2026-10-25 · โค้ด: `server/modules/act/planner.js`, `public/js/act-planner.js` · ตาราง: `mt_<act>_task` ในแม่แบบ `scripts/act-sql.js` (ทุกกิจกรรมมี)

## ใช้ที่ไหน

- 100P, SMF > Setting (หน้าเต็ม) และ Dashboard (ดูอย่างเดียว)
- 5S > Setting > แผนงาน (admin วางแผน) และ 5S > Dashboard > Schedule (ดูอย่างเดียว แม้เป็น admin) แทนแผน Gantt เดิม (ผู้ใช้สั่ง 2026-10-25) · ตารางวงกลมแผนตรวจพื้นที่ย้ายไปแท็บ Dashboard > Audit Plan
- ในแท็บของ 5S ใช้ปีของหน้า 5S (`a5Year`) และวางปุ่มลงแถวเครื่องมือของหน้า (`aplRender(body, act, { inPage, readOnly })`)

## หน้าจอ

- แถวเครื่องมือ (กฎ pageBar): ซ้าย = รายปี / รายเดือน + ค้นหา · ขวา = เลื่อนเดือน (เฉพาะรายเดือน) → สร้าง / แก้ไข / ลบ → ปี
- คอลัมน์ซ้าย: ลำดับ (1, 1.1), รายการ, ผู้รับผิดชอบ, %
- รายปี: 12 เดือน × W1–W4 (W1 = 1–7, W2 = 8–14, W3 = 15–21, W4 = 22–สิ้นเดือน) ลากแล้ววันที่ชิดต้น/ปลายสัปดาห์ · ถ้ามีรายการเลยไปปีถัดไป ตารางยาวต่อถึงเดือนสุดท้ายของรายการนั้น (เส้นเข้มคั่นปี หัวเดือนเป็น "ม.ค. 27")
- รายเดือน: เป็นวัน เสาร์–อาทิตย์แรเงา ลากทีละวัน · เลื่อนเดือนได้ตั้งแต่ ม.ค. ของปีแผนถึง ธ.ค. ปีถัดไป
- ลากกลางแท่ง = ย้าย · ลากขอบ = ยืด/หด · ลากแท่งข้อหลักที่มีข้อรอง = ย้ายข้อรองทั้งหมดเท่ากัน (ข้อหลักแบบนี้ไม่มีขอบให้ยืด)
- กด + ที่ข้อหลัก = เพิ่มข้อรอง · "+ เพิ่มข้อหลัก" ท้ายตาราง · คลิกแถว = เลือก · ดับเบิลคลิก = แก้ไข · ▾ ย่อ/ขยาย
- แท่ง: สีตามข้อหลัก (p1–p12) ส่วนทึบ = % · วันที่อยู่ข้างแท่ง · เส้นแดง = วันนี้
- คอลัมน์ยืดให้เดือนสุดท้ายชิดขอบขวา ถ้าจอแคบเลื่อนซ้าย-ขวาได้ (คอลัมน์ซ้ายติดอยู่) · หัวตารางมีเส้นคั่นแถวเดือนกับแถวสัปดาห์
- แถบเลื่อน: แนวตั้งเริ่มใต้หัวตาราง แนวนอนอยู่ใต้ส่วนแผน ไม่ทับคอลัมน์ซ้าย (กฎเดียวกับตารางอื่น app.css `.table-wrap`)

## กติกา

- admin ของกิจกรรมปีนั้น (`mt_100p_team` role admin) และ creator สร้าง แก้ ลาก ลบได้ · คนอื่นดูอย่างเดียว
- ลึก 2 ระดับ: ข้อหลัก (`parent_id` ว่าง) และข้อรอง · ข้อหลักที่มีข้อรองย้ายไปเป็นข้อรองไม่ได้
- ข้อหลักที่มีข้อรอง: ช่วงวัน = ตั้งแต่วันเริ่มแรกสุดถึงวันจบสุดท้ายของข้อรอง · % = เฉลี่ยถ่วงตามจำนวนวันของข้อรอง (`withSpans()` ทดสอบใน test:act)
- ข้อหลักที่ยังไม่มีข้อรองเว้นวันว่างได้ · ข้อรองต้องมีวันเริ่มและวันจบ
- วางแผนล่วงหน้าได้: วันที่ต้องอยู่ระหว่าง ม.ค. ของปีแผนถึง ธ.ค. ปีถัดไป (ผู้ใช้สั่ง) · ลบข้อหลักแล้วข้อรองหายด้วย
- ผู้รับผิดชอบ = รหัสพนักงาน (ค้นจาก Mx Data)
- ปฏิทินรวม (ระบบตั้งค่า > ปฏิทิน) แสดงข้อรอง และข้อหลักที่ไม่มีข้อรอง · % = 100 แสดงเป็น "เสร็จแล้ว"

## ตาราง `mt_<act>_task` (Tx Data)

| คอลัมน์ | ความหมาย |
|---|---|
| id, year | ปีของแผน |
| parent_id | ว่าง = ข้อหลัก · มีค่า = ข้อรองของข้อหลักนั้น (on delete cascade) |
| sort_no | ลำดับในระดับเดียวกัน (เพิ่มใหม่อยู่ท้าย) |
| title, note | ชื่อ / รายละเอียด |
| start_date, end_date | มีทั้งคู่หรือว่างทั้งคู่ end ≥ start |
| progress | 0–100 |
| owner_id | employee_id |
| color | p1–p12 (ข้อหลัก) |
| created_by, created_at, updated_at | |

## API

- `GET /api/act/:activity/tasks?year=` → `{ tasks (มี derived, owner_name), canEdit, admins }`
- `POST /api/act/:activity/tasks` · `PATCH /api/act/:activity/tasks/:id` · `DELETE /api/act/:activity/tasks/:id`
- `PATCH /api/act/:activity/tasks/dates` `{ year, items: [{ id, startDate, endDate }] }` (ลาก)

## เปิดใช้กับกิจกรรมอื่น

1. กิจกรรมใหม่: `node scripts/act-sql.js <act> --no-audit` (หรือไม่ใส่ `--no-audit` ถ้ามีระบบตรวจด้วย) ตาราง Planner มาด้วยเสมอ · กิจกรรมที่ใช้งานอยู่ก่อนมี Planner: `node scripts/act-sql.js <act> --add-task` → `db/act/<act>_task.sql` (สร้างตารางและคัดลอกแผน Gantt เดิมครั้งเดียว: 1 ชื่อ = 1 ข้อหลัก ชื่อที่มีหลายช่วง = ข้อหลัก + ข้อรอง ไม่เอาที่ยกเลิก) แล้วรันใน Tx Data
2. เพิ่ม id ใน `PLANNER_ON` (planner.js) และ `APL_ON` (act-planner.js) · ถ้ากิจกรรมนั้นใช้หน้า Setting ของ 5S อยู่แล้วต้องวางหน้า Planner เป็นแท็บแทน

## เทียบแผนกับผลจริง (ผู้ใช้สั่ง 2026-10-29)

- `done_on` (date) วันที่ทำครบ 100%: กรอกในฟอร์ม (ช่อง "วันที่ทำเสร็จ" โผล่เมื่อ % = 100 ค่าเริ่ม = วันนี้ ห้ามเป็นวันในอนาคต) · ไม่กรอก = วันนี้ตอนที่เพิ่งครบ 100 · ลด % ต่ำกว่า 100 = ล้าง · รายการที่ 100 อยู่แล้วก่อนมีคอลัมน์ = ไม่รู้วันเสร็จ แสดง "เสร็จแล้ว"
- ข้อหลักที่มีข้อรอง: เสร็จเมื่อข้อรองครบทุกข้อ วันเสร็จ = วันของข้อรองที่เสร็จหลังสุด
- สถานะ (`planStatus` ใน server/modules/act/planner.js): เสร็จก่อนแผน N วัน / เสร็จตามแผน / เสร็จช้า N วัน · ยังไม่ครบ: เลยกำหนด N วัน (เลยวันจบ) · ยังไม่ถึงกำหนด · ช้ากว่าแผน / ตามแผน / เร็วกว่าแผน เทียบ % จริงกับ % ที่ควรได้ถึงวันนี้ (เส้นตรงจากวันเริ่มถึงวันจบ) ต่างไม่เกิน 10 จุด = ตามแผน
- หน้าจอ: จุดสีหน้า % (เขียว เสร็จ · น้ำเงิน ตาม/เร็วกว่าแผน · ส้ม ช้ากว่าแผน · แดง เลยกำหนด/เสร็จช้า) · ข้อความสถานะต่อท้ายช่วงวันข้างแท่ง (ถ้ามีที่) และใน tooltip ของแท่ง · คำอธิบายสีใต้ตาราง
- ไม่มีคอลัมน์ `done_on` (ยังไม่รันไฟล์ SQL รอบใหม่): server บันทึกโดยไม่ใส่วันเสร็จ หน้าจอยังใช้ได้
- แท่ง (ผู้ใช้สั่ง 2026-10-29 รอบ 3, แบบแถว P / A ใน Excel Master Plan 5ส): ต่อแถวมี 2 แถบบาง 9px **บน = แผน** (อ่อน ลากได้) **ล่าง = ทำจริง** (เข้ม, % ท้ายแถบ, ส่วนเลยวันจบสีแดง) · ยังไม่มี % = ไม่มีแถบล่าง
- แท่ง (รอบ 2, เดิม): **แถบอ่อน = แผน** (วันเริ่ม → วันจบ ลากย้ายได้) · **แถบเข้ม = ดำเนินการจริง** จากวันเริ่มถึงวันเสร็จ (`done_on`, เสร็จก่อนแผน = สั้นกว่าแถบอ่อน) หรือถึงวันนี้ถ้ายังไม่เสร็จ · ส่วนที่เลยวันจบเป็น**สีแดง** · % อยู่ท้ายแถบเข้ม · แท่งสูง 16px
- หน้าตา (ผู้ใช้สั่ง 2026-10-29): แถวสูง 28px แท่ง 20px ขอบ 1px ทุกแท่ง · รายการ / ผู้รับผิดชอบ ตัวปกติ 12px ผู้รับผิดชอบไม่มีคำนำหน้า · ไม่มีปุ่ม + ต่อแถว: เพิ่มข้อรอง = เลือกข้อหลักแล้วกด "สร้าง" · เส้นวันนี้ (แดง) อยู่บนแท่ง
